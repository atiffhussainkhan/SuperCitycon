**Date:** 2026-11-09
**Audited revision:** `92c0b37` (the `main` branch HEAD)

**Method:** direct source reading, targeted grep/find over `game/src`, and the project's own test suite and acceptance harness. No feature is called complete because a document says so — every row below names the code that implements it, or says **absent** and names the pattern that was checked.

### The ten domains

`src/core/` (CORE) · `src/world/` (WLD) · `src/buildings/` (BLD) · `src/economy/` (ECO) · `src/mobility/` (MOB) · `src/population/` (POP) · `src/services/` (SRV) · `src/studio/` (STD) · `src/ui/` (UX) · `src/render/` + `src/audio/` (TEC)

## 4. What V4 got right (and V5 must not break)

1. **The requirement dossier.** 1,869 tracked requirement ids with sources. It is the reason the game can be audited at all, and it is the backlog V5 works from.
2. **The domain contract and the honesty discipline.** Pure rule modules that cannot import `three`, art that can only come from the manifest, and unpublished numbers that must live in `TUNING` and be marked `TBD`.
3. **The placement gate.** A refused placement is explained to the player and is not charged.
4. **The traffic simulation.** BFS routing, congestion, stuck detection, rerouting — a genuinely well-built system.
5. **The instancing layer.** Per-model batching, a growable slot pool, static merging, a post-hoc scene sweep.
6. **The audio synthesiser.** A complete bus mixer with no asset-licence exposure at all.
7. **The save validation.** Corrupt JSON, an unsupported version and a structurally invalid city are each caught and reported, not silently loaded.
8. **The cleared-build pipeline.** The publishable build strips the licence-unverified 2D art and the build **fails** if any of it survives.

---

## 5. The five findings that matter most

1. **The day counter double-increments** — a shipped correctness bug, verified empirically (day 1 → 3 per 60 s). The HUD's day number disagreed with the world.
2. **The simulation is frame-rate dependent** — a domain's decay rate was the monitor's refresh rate.
3. **A complete audio mixer that never played** — the game was silent, and the UI had no volume control.
4. **Two clocks and two owners for speed/pause** — one of each pair was dead code, and the two emitted incompatible payloads.
5. **No teardown path** — nothing could be stopped, so every reload leaked a frame loop and a timer.

Each is addressed in `V5_UPGRADE_PLAN.md` and tracked in `V5_REQUIREMENTS_MATRIX.md`.
