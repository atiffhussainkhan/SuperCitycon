# SuperCitycon — project rules

Read `src/core/CONTRACT.md` before writing code. It is binding.

## Hard rules

1. **Art comes only from the asset library.** The single source of truth is
   `src/data/manifest.json` (generated by `tools/build_manifest.py` from
   `../tools/build_manifest.py`). Never hard-code a model path. Never
   generate, redraw or substitute art. The library's 2D image packs are
   `licence_status: unverified` and must never be shipped.
2. **Do not edit files you do not own.** Each domain owns one folder. The
   integrator owns `src/main.js`, `src/core/config.js`, `src/core/events.js`,
   `src/core/state.js`, `src/core/CONTRACT.md`, `src/render/renderer.js`,
   `src/render/assets.js`, `src/data/manifest.json` and `index.html`.
3. **Unpublished numbers are `TUNING` values.** If the publisher never
   published a number, do not hard-code a guess — use an existing `TUNING`
   key, or define a clearly `// TBD:`-marked constant in your own module and
   propose the `TUNING` addition in your report.
4. **Pure logic stays pure.** Modules that hold game rules must not import
   `three`, so they can be unit-tested in Node.
5. **Verify before claiming.** Run the commands. Paste the real output.
   Never say a test passed that you did not run.

## Grid and units

- One grid cell = **4 world units**. The grid is **64 × 64 cells**
  (256 × 256 world units).
- World origin `(0, 0)` is the **centre** of the grid. Cell `(0, 0)` is the
  south-west corner.
- Use `config.cellToWorld` / `config.worldToCellInt` / `config.cellKey`
  rather than doing arithmetic yourself.

## Commands

```bash
cd game
npm run dev            # vite dev server
npm run check          # node --check over every source file
npm test               # node --test
npm run build          # vite build -> dist/
```

From the workspace root:

```bash
python3 tools/build_manifest.py                 # regenerate the asset manifest
node tools/shoot.mjs http://localhost:5177/ out.png 12000 1600 1000
```

## Where the spec lives

`../docs/requirements/<domain>.md` — one per domain, each with
`FR-<DOMAIN>-NNN` rows carrying a **Priority** (Must / Should / Could),
a **Stage**, and an acceptance-criteria id. Implement **Must** first.
`../docs/SUPER-CITYCON-MASTER-REQUIREMENTS.md` is the merged reference.
